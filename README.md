# 퇴근하지 못한 사람들 — AI 건설현장 위험 감지

건설현장 사진을 AI로 분석해 위험 요소를 감지하고, 작업자의 모국어로 음성 경보를 전달하는 웹 서비스입니다.

🔗 **Live Demo:** https://safetydemo-nine.vercel.app

## 배경

국민대학교 교양 수업 "인공지능과 창의적사고" 팀 프로젝트로 시작했습니다. 건설현장 사고 예방이라는 문제의식에서 출발해, 웹 개발 경험이 전혀 없는 상태로 기획부터 구현·배포까지 직접 진행했습니다.

## 주요 기능

- **위험 분석**: 현장 사진을 업로드하면 AI가 안전모·안전벨트 미착용, 추락 위험 자세 등을 감지
- **위험도 시각화**: 감지된 위험 요소를 사진 위에 바운딩 박스로 표시하고 종합 위험도 점수(0~100) 제공
- **다국어 음성 경보**: 한국어·베트남어·태국어·중국어·영어 지원 — 국내 건설현장의 외국인 근로자를 고려한 설계
- **데모 모드**: API 연결 없이도 사전 준비된 결과로 동작을 확인할 수 있는 폴백 모드
- **아차사고 로그**: 분석 이력을 누적해 향후 모델 재학습 데이터로 활용 가능하도록 설계

## 기술 스택

- **Frontend**: React (CDN 방식, 별도 빌드 과정 없이 단일 HTML 파일로 구성)
- **Backend**: Vercel Serverless Function (`/api/analyze`)
- **AI 분석 엔진**: Google Gemini API
- **배포**: Vercel

## 실행 흐름

\```
사진 업로드 → AI 분석 요청 (/api/analyze) → 위험 요소 감지 및 위험도 산출 → 시각화 + 음성 경보 생성
\```

## 배운 점

전공(기계공학)과 무관해 보였던 웹 개발에 처음 뛰어들며, 프론트엔드 구조부터 서버리스 API 연동까지 필요한 기술을 그때그때 스스로 학습하며 완성했습니다. 특히 실제 서비스가 API 키 만료 등 외부 요인으로 언제든 멈출 수 있다는 점을 고려해, 데모 모드라는 폴백 장치를 직접 설계해 넣었습니다.
